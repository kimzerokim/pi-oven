# Deterministic Report Sections

Use these top-level headings in this exact order:

1. Executive Summary
2. Scope and Method
3. Key Findings
4. Evidence Matrix
5. Risks and Unknowns
6. Recommendations
7. Source Bibliography
8. Appendix (optional, only when populated)

## Section minimums

- Executive Summary: 3-7 bullets.
- Scope and Method: scope boundary, inclusion/exclusion, method steps.
- Key Findings: grouped by topic.
- Evidence Matrix: one row per major claim with citation.
- Risks and Unknowns: explicit uncertainty + impact.
- Recommendations: normalized recommendation blocks only.
- Source Bibliography: deduplicated source list with URLs.
- Appendix: supplemental tables only.
