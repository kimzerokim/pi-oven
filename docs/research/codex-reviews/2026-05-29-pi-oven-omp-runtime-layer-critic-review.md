## 🔴 BLOCKERS (must fix before implementation)

- **B1 — `tool_call` hook has NO timeout (spec §2 row6 / §3 Layer1 / AC2 false premise).** `emitToolCall` (`extensions/runner.ts:614-647`) awaits the handler **directly** — the only emit path NOT wrapped by `#runHandlerWithTimeout` (30s `EXTENSION_HANDLER_TIMEOUT_MS` applies to session/turn/agent/context emits only). A *thrown* error fail-closes (`{block:true}`, true) but a *hung* handler deadlocks the agent forever. Fix: correct the claim; Layer 1 must self-impose an internal deadline (`Promise.race`, pick a number e.g. 200ms–2s) and throw-to-block on overrun; rewrite AC2 around the self-deadline (drop "never exceeds 30s").
- **B2 — no failure policy for corrupted/missing/partial state.** Single `.pi-oven/state/autonomous.json` read in-hook; a `JSON.parse` throw bricks ALL gated tools (can't even `git commit` to recover). Fix: per-tool fail-closed/open + env escape hatch + atomic write (temp+rename) + ACs for corrupt/missing/partial.
- **B3 — git gating via string match is trivially bypassable.** `git -C`, `bash -lc`, heredocs, aliases, env-prefix, multiline all evade. Fix: canonical command normalization OR document best-effort + residual bypass surface + adversarial ACs.
- **B4 — no concurrency/atomicity for the single-file FSM.** `tool_call` fires before every tool incl. task-spawned subagents → concurrent writers. Fix: atomic update / single-writer + stale-cache invalidation + parallel/nested-subagent ACs.
- **B5 — scope contradiction: task-dispatch phase-gating is "core Layer 1" but "optional/out-of-scope" in §5/§7; §6 ACs never test it.** Fix: pick minimal v1 scope (commit/push/forbidden only); move task-phase-gating to a labeled Phase 2; acknowledge native static primitives (`task #blockedAgent`/`allowedSpawns` `task/index.ts:794,816`; `disabledAgents` `:619-625`) are static-not-phase-aware.
- **B6 — AC2/AC3 untestable as written.** No numeric threshold; "simulated compaction" fixture undefined. Fix: AC2 → concrete budget (p95 < ~50ms cache-hit; self-abort at N ms); AC3 → fixture sequence (inject → `session.compacting` writes `preserveData` → `before_agent_start` with `branchEntries` re-injects, asserting a named dedup key prevents duplicates). Persistence substrate confirmed real (`session-manager.ts:116,652,2737-2750`; `agent-session.ts:6373-6398`).
